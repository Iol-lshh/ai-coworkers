# ADR-0010: 조건 판정은 구현체에 위임함

- 상태: 대체됨 ([ADR-0011](0011-condition-tree-in-template.md))
- 날짜: 2026-10-25

## 맥락

- 분기와 반복은 조건으로 다음 슬롯을 고름.
- 템플릿 스냅샷을 저장하려면 조건을 데이터로 가리킬 수 있어야 함.
- 조건 종류별 구현체는 별도 프레임워크로 만들 예정임.

## 결정

- 조건은 식별자와 판정만 가짐.
- 판정 방식은 조건 구현체가 정함.

## 결과

- 템플릿 스냅샷은 조건 대신 조건 식별자를 저장함.
- 조건 식별자로 구현체를 찾는 등록부, 설정값을 받는 조건의 저장 방식은 조건 프레임워크에서 정함.
