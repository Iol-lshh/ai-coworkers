# ADR-0009: 완성 검증은 빌더, 규칙 검증은 생성자가 맡음

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 슬롯은 빌더를 거치는 경로와 생성자를 직접 호출하는 경로로 모두 만들어질 수 있음.
- 빌더는 값을 채우는 도중의 가변 상태를 가짐.

## 결정

- 빌더의 완성 메서드는 필수 값이 모두 채워졌는지만 검증함.
- 슬롯이 항상 지켜야 하는 규칙은 슬롯 생성자가 검증함.
- 목록 값의 불변 복사는 슬롯 생성자가 함.
- 생성자는 널을 검사하지 않음. 널 검사는 정적 분석이 맡음.

## 결과

- 찍어내기, 복원, 직접 생성이 같은 규칙을 거침.
- 슬롯 종류별 규칙의 구체 목록은 미정이고, 생성자 검증은 미구현임.
