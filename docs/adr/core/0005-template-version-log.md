# ADR-0005: 템플릿 버전을 식별자와 분리하고 로그 스냅샷으로 보존함

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 템플릿이 수정되면, 이미 찍어낸 워크플로우를 복원할 때 동작과 구조가 어긋날 수 있음.
- 템플릿 버전을 식별자와 묶어 버전마다 행을 두는 방식도 검토함.

## 결정

- 템플릿은 식별자와 별개로 버전을 가짐.
- 템플릿 현재본은 식별자 하나로 저장하고, 수정하면 같은 행을 갱신하며 버전을 올림.
- 템플릿을 저장할 때마다 그 시점의 스냅샷을 템플릿 로그에 추가함. 첫 버전도 포함함.
- 템플릿 로그는 추가만 하고 수정하지 않음.

## 결과

- 현재본의 버전은 낙관적 잠금 버전으로 매핑할 수 있음.
- 슬롯 복원은 템플릿 식별자와 버전으로 템플릿 로그에서 읽음.
- 현재본 저장과 로그 추가는 같은 트랜잭션에서 함.
- 스냅샷은 데이터로 저장할 수 있어야 함. 조건은 트리 값으로 저장함. [ADR-0011](0011-condition-tree-in-template.md)을 따름.
