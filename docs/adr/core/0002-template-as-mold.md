# ADR-0002: 템플릿을 틀로 두고 슬롯을 찍어냄

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 다음 단계를 템플릿 식별자로 가리키면, 같은 템플릿이 한 워크플로우에 두 번 들어갈 때 어느 자리인지 구분할 수 없음.
- 템플릿 묶음은 여러 워크플로우에 반복해서 쓰는 틀임.

## 결정

- 템플릿은 다음 템플릿의 식별자를 가짐.
- 한 틀 안에서 템플릿 식별자는 중복되지 않음.
- 슬롯 팩토리가 틀을 받아 템플릿마다 슬롯을 하나씩 찍어냄.
- 같은 틀을 여러 번 찍으면 찍을 때마다 새 슬롯 식별자가 생김.

## 결과

- 같은 동작이 한 틀의 두 자리에 필요하면 템플릿을 둘 만듦.
- 연결의 원천은 템플릿이고, 슬롯의 연결은 찍어낸 결과물임.
- 시작 템플릿과 템플릿 목록을 묶는 틀 타입은 미구현임.
