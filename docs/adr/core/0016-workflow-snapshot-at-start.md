# ADR-0016: 실행은 처음 실행하는 시점의 워크플로우 틀 버전과 템플릿을 고정함

- 상태: 수락됨
- 날짜: 2026-10-26

## 맥락

- 워크플로우 틀은 시작 템플릿과 템플릿 목록을 묶음. [ADR-0002](0002-template-as-mold.md)를 따름.
- 실행 중에 틀이나 템플릿이 수정될 수 있음.
- 슬롯은 템플릿 객체를 보유함. [ADR-0004](0004-slot-holds-template.md)를 따름.

## 결정

- 워크플로우 틀은 식별자, 버전, 시작 템플릿 식별자, 템플릿 식별자 목록을 가짐.
- 틀의 버전과 로그는 템플릿과 같은 방식으로 관리함. [ADR-0005](0005-template-version-log.md)를 따름.
- 틀은 템플릿 버전을 고정하지 않음.
- 실행을 시작할 때 틀 현재본과 그 템플릿 현재본으로 슬롯을 찍음.
- 실행은 시작 시점의 틀 식별자와 버전을 기록함.

## 결과

- 시작한 뒤에 틀이나 템플릿을 수정해도 진행 중인 실행에는 반영되지 않음.
- 실행 복원은 틀 로그와 템플릿 로그에서 기록된 버전을 읽음.
- 틀 안의 템플릿 연결 검증은 찍어낼 때 슬롯 팩토리가 맡음.
