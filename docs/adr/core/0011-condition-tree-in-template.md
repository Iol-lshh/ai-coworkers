# ADR-0011: 분기·반복 템플릿이 조건 트리를 값으로 보유함

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 분기와 반복은 여러 조건을 조합해 판정할 수 있어야 함.
- 조건을 식별자로 저장하면 조건 내용과 템플릿 버전이 따로 바뀌어, 스냅샷만으로 당시 판정을 재현할 수 없음.
- 조건은 분기·반복 템플릿에 딸린 판정 규칙이며 독자적인 생명주기가 없음.

## 결정

- 분기·반복 템플릿은 조건 트리를 값으로 보유함.
- 조건 트리의 노드는 조합 노드와 말단 노드로 나눔.
- 조합 노드는 전부 만족, 하나 이상 만족, 부정이며 자식 노드만 가짐.
- 말단 노드는 조건 종류 코드와 설정값을 가짐.
- 말단 노드의 판정 방식은 조건 종류 코드에 대응하는 구현체가 정함.
- 템플릿 스냅샷은 조건 트리 전체를 담음.
- 조건 트리의 버전은 템플릿 버전을 따름. 조건을 고치면 템플릿 버전이 오름.

## 결과

- 템플릿 로그의 스냅샷 하나로 당시 판정을 재현함.
- 조건 트리 안의 노드에는 식별자를 두지 않음.
- 조건 종류 코드로 구현체를 찾는 등록부가 필요함.
- 여러 템플릿에 걸친 조건 재사용은 지원하지 않음.
- 조건 트리의 조립·복원은 [ADR-0012](0012-closed-condition-tree.md), 저장 형식 변환은 [ADR-0014](0014-neutral-form-and-serd-module.md)를 따름.
