# ADR-0014: core는 중립 형태까지 변환하고 문자열 형식은 serd 모듈이 맡음

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- core는 JDK와 core 자신에만 의존함.
- 조건 트리의 구조 지식은 core에만 있어야 함. [ADR-0012](0012-closed-condition-tree.md)를 따름.
- 저장소 어댑터가 여럿이어도 문자열 형식 변환은 같아야 함.

## 결정

- core는 도메인 객체와 JDK 타입만 쓰는 중립 형태 사이를 변환함.
- 중립 형태에서 도메인 객체로 바꿀 때 도메인 규칙 검증을 모두 거침.
- 중립 형태와 문자열 형식 사이의 변환은 형식별 serd 모듈이 맡음. 모듈 이름은 `serd-{형식}`임.
- 저장소 어댑터는 serd 모듈을 거쳐 문자열을 저장하고 읽음.
- serd 모듈은 형식이 맞지 않는 문자열을 거부함.

## 결과

- 문자열 형식을 바꾸거나 추가해도 core는 바뀌지 않음.
- 조건 트리의 JSON 변환은 `serd-json` 모듈이 맡음.
- 단계 입력과 템플릿 스냅샷 전체의 변환은 미구현임.
