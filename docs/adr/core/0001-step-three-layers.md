# ADR-0001: 단계를 템플릿·슬롯·노드로 나눔

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 단계 하나가 동작 정의, 워크플로우 안의 위치, 실행 상태를 함께 가지면 바뀌는 이유가 셋이 됨.
- 같은 동작을 여러 워크플로우와 여러 자리에서 재사용해야 함.
- 같은 워크플로우를 여러 번 실행하고, 반복으로 같은 자리를 여러 번 실행함.

## 결정

- 템플릿은 동작의 정의를 맡음.
- 슬롯은 템플릿을 워크플로우의 한 자리에 놓고 다음 슬롯을 이음.
- 노드는 슬롯을 한 번 실행한 상태를 맡음.
- 노드는 미리 만들지 않고, 실행이 슬롯에 도착할 때 만듦.

## 결과

- 동작 수정, 구조 수정, 실행 진행이 각각 한 계층만 바꿈.
- 반복 횟수만큼 같은 슬롯에서 노드가 여러 개 생김.
- 노드 상태의 구체 형태는 미정임.
