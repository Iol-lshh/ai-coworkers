# ADR-0004: 슬롯이 템플릿을 직접 보유함

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 실행할 때마다 템플릿 식별자로 템플릿을 조회하면 실행 경로가 저장소에 의존함.
- 단계 종류는 템플릿에서 알 수 있음.

## 결정

- 슬롯은 템플릿 식별자 대신 템플릿 객체를 보유함.
- 슬롯의 처리는 템플릿의 동작을 실행하고, 다음 슬롯을 출력에 담음.
- 실행 중 다음 슬롯은 슬롯에서만 찾음. 템플릿의 다음 템플릿은 찍어낼 때 팩토리만 읽음.

## 결과

- 슬롯에 단계 종류 필드를 따로 두지 않음.
- 복원할 때 템플릿 식별자와 버전으로 템플릿을 다시 얻는 경로가 필요함. [ADR-0005](0005-template-version-log.md)를 따름.
