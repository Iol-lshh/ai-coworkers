# ADR-0012: 조건 트리를 닫고 말단 조건 종류로만 확장함

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 조건 트리를 아무 구현이나 받도록 열어 두면, 복원할 수 없는 조건이 템플릿에 들어갈 수 있음.
- 조건 트리를 저장 형태로 바꾸는 규칙과 다시 조립하는 규칙은 한 곳에 있어야 함.
- 잘못된 설정값이 실행 중에 드러나면 이미 진행한 흐름이 중간에 멈춤.

## 결정

- 조건 트리의 노드 종류는 조합 노드 셋과 말단 노드 하나로 닫음.
- 노드 타입은 조건 패키지 안에서만 보임. 패키지 밖에는 판정만 드러냄.
- 조건 트리를 만들고 복원하는 일은 조건 패키지 안의 진입점이 맡음.
- 새 판정 방식은 조건 종류를 구현해 말단 노드에 넣는 방식으로만 추가함.
- 조건 종류는 말단 노드를 만들 때 설정값을 검증하고, 맞지 않으면 거부함.
- 판정할 값이 입력에 없거나 값의 종류가 다르면 조건을 만족하지 않은 것으로 판정함.

## 결과

- 템플릿에 들어간 조건 트리는 항상 저장하고 복원할 수 있음.
- 잘못된 설정값은 템플릿을 만들 때 거부됨.
- 판정은 입력의 형태 때문에 실패하지 않음.
- 조건 트리 조립·복원 진입점은 중립 형태를 입출력으로 씀. [ADR-0014](0014-neutral-form-and-serd-module.md)를 따름.
