# ADR-0015: 템플릿을 JSON 본문으로 저장하고 직전 버전 조건부 갱신으로 낙관적 잠금함

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 템플릿 현재본은 식별자 하나로 저장하고 수정마다 버전을 올림. [ADR-0005](0005-template-version-log.md)를 따름.
- 템플릿 종류마다 필드가 다르고, 조건 트리는 값으로 보유함. [ADR-0011](0011-condition-tree-in-template.md)을 따름.
- 도메인 서비스의 버전 검사만으로는 동시에 들어온 수정을 막지 못함.

## 결정

- 현재본 테이블은 식별자, 버전, JSON 본문을 가짐.
- 로그 테이블은 로그 식별자, 템플릿 식별자, 버전, JSON 스냅샷, 등록 시각을 가짐.
- JSON 본문과 스냅샷은 템플릿 전체를 담음. 변환은 [ADR-0014](0014-neutral-form-and-serd-module.md)를 따름.
- 현재본 저장은 같은 식별자의 직전 버전 행을 갱신함. 갱신할 행이 없고 같은 식별자의 행도 없으면 추가함.
- 같은 식별자의 다른 버전 행이 있으면 충돌로 거부함.
- 페이지 조회는 식별자 순으로 정렬함.

## 결과

- 템플릿 종류를 추가해도 테이블 구조는 바뀌지 않음.
- 동시에 들어온 수정 중 하나만 반영되고 나머지는 충돌로 거부됨.
- 본문 안의 필드로는 조회하지 않음.
- 작업 템플릿은 저장 형태가 없어 저장을 거부함.
