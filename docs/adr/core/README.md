## 개념 관계

```mermaid
flowchart LR
  T[템플릿] -->|수정마다 스냅샷| TL[템플릿 로그]
  T -->|팩토리가 찍어냄| S[슬롯]
  S -->|보유| T
  N[노드] -->|실행하는 자리| S
  SG[사가] -->|현재 노드| N
  SG -->|변경마다 스냅샷| SL[사가 로그]
  W[워크플로우] -->|병렬 갈래 관리| SG
```

| 개념 | 책임 | 바뀌는 시점 |
|---|---|---|
| 워크플로우 | 사가 오케스트레이션 | 사가가 생기거나 끝날 때 |
| 사가 | 흐름 오프셋 | 노드가 바뀔 때 |
| 템플릿 | 스텝 정의 | 템플릿을 수정할 때 |
| 슬롯 | 스텝 배치 | 템플릿으로 찍어낼 때 |
| 노드 | 스텝 인스턴스 | 실행이 진행될 때 |
