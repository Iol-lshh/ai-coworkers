# ADR-0006: 식별자를 UUID v7로 각각 발행함

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 식별자는 저장소에 의존하지 않고 도메인에서 발행해야 함.
- 기본키로 쓸 때 생성 순서로 정렬되면 인덱스에 유리함.
- 프로젝트 toolchain인 Java 25 표준 라이브러리에는 UUID v7 생성 메서드가 없음.
- 슬롯 식별자를 워크플로우 식별자와 템플릿 식별자의 조합으로 만드는 방식도 검토함.

## 결정

- 공통 패키지에 UUID v7 생성기를 둠. 생성기는 UUID만 반환함.
- 도메인 식별자는 각자 UUID를 감싸는 타입으로 둠.
- 슬롯 식별자를 포함한 모든 식별자를 조합하지 않고 각각 발행함.

## 결과

- 공통 패키지가 도메인 식별자 타입을 참조하지 않음.
- 슬롯 팩토리는 템플릿 식별자와 슬롯 식별자의 대응표를 먼저 만든 뒤 슬롯을 조립함.
- 식별자에서 생성 시각이 드러남.
- toolchain을 26 이상으로 올리면 표준 라이브러리 생성 메서드로 바꿀 수 있음.
