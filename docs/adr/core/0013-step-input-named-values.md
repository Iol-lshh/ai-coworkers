# ADR-0013: 단계 입력을 이름 붙은 값 묶음으로 둠

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 조건은 입력만으로 결정적으로 판정해야 함.
- 조건 설정값은 판정할 값을 이름으로 가리켜야 함.
- 사람의 응답처럼 한 입력에 여러 값이 함께 들어올 수 있음.

## 결정

- 단계 입력은 이름별 값의 불변 묶음임.
- 값 종류는 논리값, 숫자값, 문자열값으로 닫음.
- 숫자값은 십진 정밀 숫자 하나로 표현함. 정수와 실수는 생성 경로로만 구분함.
- 유한하지 않은 실수는 숫자값으로 만들지 않음.
- 입력의 저장 형태는 어댑터가 정하며 JSON으로 저장함.

## 결과

- 숫자 비교는 표현 방식과 관계없이 한 규칙으로 함.
- 판정할 수 없는 값은 앞 단계에서 세 값 종류로 바꿔 입력에 담아야 함.
- 목록 값은 지원하지 않음.
- 입력 저장은 미구현임.
