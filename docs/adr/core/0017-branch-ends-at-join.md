# ADR-0017: 갈래는 합류 슬롯에 도착하면 끝나고 실행 객체가 합류 대기를 관리함

- 상태: 수락됨
- 날짜: 2026-10-26

## 맥락

- 병렬 갈래는 사가를 여러 개 만들어 표현하고, 사가에 부모 사가를 두지 않음. [ADR-0008](0008-saga-single-flow.md)을 따름.
- 병렬 슬롯은 갈래 슬롯 목록과 합류 슬롯을 가짐.

## 결정

- 사가는 진행, 대기, 합류, 종료 상태를 가짐. 진행과 대기 상태만 현재 노드를 가짐.
- 병렬 출력을 받으면 분기한 사가는 현재 노드에서 대기하고, 갈래마다 새 사가를 만듦.
- 워크플로우 실행 객체는 분기마다 대기한 사가, 갈래 사가, 합류 슬롯, 도착한 갈래를 담은 합류 대기를 둠.
- 갈래 사가가 자기 분기의 합류 슬롯으로 가면 노드를 만들지 않고 합류 상태로 끝남.
- 갈래가 모두 도착하면 합류 대기를 지우고 대기한 사가가 합류 슬롯으로 옮겨감.
- 갈래 사가가 합류 슬롯에 닿기 전에 끝나면 진행을 거부함.

## 결과

- 각 갈래의 마지막 템플릿은 병렬 템플릿의 합류 템플릿을 다음 템플릿으로 가리켜야 함.
- 중첩 병렬은 안쪽 분기가 합류한 뒤 대기한 사가가 바깥 분기의 갈래로 이어감.
- 갈래가 없는 병렬은 대기 없이 합류 슬롯으로 옮겨감.
- 진행할 때마다 바뀐 사가만 사가 로그에 스냅샷을 추가함.
