# ADR-0008: 사가는 흐름 하나의 현재 위치만 보유함

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- 병렬 단계가 있으면 동시에 진행하는 흐름이 여럿 생김.
- 실행을 멈췄다가 이어가려면 흐름마다 현재 위치와 지나온 이력이 필요함.

## 결정

- 사가는 흐름 하나가 지금 가리키는 노드만 보유함.
- 사가의 이전 상태는 사가 로그의 스냅샷으로 보존함. 사가에 이전 노드를 두지 않음.
- 병렬 갈래는 사가를 여러 개 만들어 표현함.
- 사가 사이의 분기·합류 관계는 워크플로우 실행 객체가 관리함. 사가에 부모 사가를 두지 않음.

## 결과

- 보상 순서는 사가 로그를 거꾸로 따라가 정함.
- 여러 사가에 걸친 보상 순서는 워크플로우 실행 객체가 정함.
- 워크플로우 실행 객체와 보상 동작은 미구현임.
