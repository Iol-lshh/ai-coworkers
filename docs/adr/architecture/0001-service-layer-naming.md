# ADR-0001: 애플리케이션 서비스는 core 밖의 `Service`, 도메인 서비스는 core의 `Processor`로 둠

- 상태: 수락됨
- 날짜: 2026-10-25

## 맥락

- core는 JDK와 core 자신에만 의존함.
- 저장소 조율과 트랜잭션 경계는 프레임워크에 의존함.
- `Service`는 다른 `Service`에, `Facade`는 다른 `Facade`에 의존하지 않음.

## 결정

- 애플리케이션 서비스는 core 밖 실행 모듈에 두고 이름을 `*Service`로 끝냄.
- 애플리케이션 서비스는 트랜잭션 경계를 맡고 도메인 서비스에 위임함.
- 도메인 서비스는 core에 두고 이름을 `*Processor`로 끝냄.
- 도메인 서비스는 유스케이스의 흐름과 규칙을 맡음.
- 도메인 서비스는 저장소 동작을 생성 시점에 함수로 받음. 저장소 타입과 트랜잭션은 모름.
- 저장소 동작을 함수로 연결하는 일은 도메인 서비스를 쓰는 애플리케이션 서비스가 생성 시점에 맡음.
- 여러 애플리케이션 서비스를 조합하는 유스케이스는 `*Facade`가 맡음.

## 결과

- core에 `*Service`가 있거나 `*Processor`가 `*Repository`에 의존하면 core 아키텍처 테스트가 실패함.
- `*Processor`는 `TaskStepTemplate.process`의 작업 실행과 다른 뜻임.
