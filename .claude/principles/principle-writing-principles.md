# 원칙 작성 원칙

- 하나의 원칙 문서는 20줄 이내로 작성할 것.
- 한 줄에 규칙 하나만 작성할 것.
- "적절히", "가능하면", "필요시" 같은 판단 불가 표현 금지.
- Claude 기본 행동과 겹치는 규칙, 다른 원칙 문서와 충돌하는 규칙 금지.
- 파일명은 `{주제}-principles.md`, 위치는 `.claude/principles/`.
- 매 세션 필요한 원칙은 CLAUDE.md "항상 적용"에 `@경로`로 등록할 것.
- 특정 상황에만 필요한 원칙은 CLAUDE.md "상황별 적용" 표에 상황과 `경로`로 등록할 것. `@` 금지.
